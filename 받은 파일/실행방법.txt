고령자 디지털 소외 위험 예측 - Python 분석 실행방법

포함 파일
1. elderly_digital_gap_python_analysis_pause.py
2. 2025 정보격차 고령층.arff
3. requirements.txt

실행방법
1. ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. Python이 설치되어 있어야 합니다.
3. 아래 패키지가 없다면 명령 프롬프트(CMD)에서 설치합니다.

   pip install -r requirements.txt

4. elderly_digital_gap_python_analysis_pause.py 파일을 실행합니다.
5. 같은 폴더에 ARFF 파일이 있으므로 자동으로 불러옵니다.
6. 분석이 끝나면 같은 폴더에 python_analysis_outputs 폴더가 생성됩니다.

주의
- 더블클릭 실행 시에도 마지막에 Enter를 눌러야 창이 닫히도록 되어 있습니다.
- 오류가 발생해도 오류 메시지가 화면에 남도록 수정되어 있습니다.
